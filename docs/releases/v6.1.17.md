## First release from this fork

This is `Y0UW1SH/chatgpt-web-codex` v6.1.17: upstream
[codex-chatgpt-web v6.1.17](https://github.com/miuuyy/codex-chatgpt-web/releases/tag/v6.1.17) plus
this fork's fixes. **[See everything that differs from upstream →](https://github.com/Y0UW1SH/chatgpt-web-codex/blob/main/docs/fork-changes.md)**

### Improvements over upstream v6.1.17

- **Runtime reliability:**
  - incomplete compaction checkpoints are rejected;
  - JSON and streamed responses report the same terminal status;
  - stream errors are never dropped;
  - turns drain before tunnel changes;
  - stale helper and runtime owners can no longer complete or take over a newer turn.
- **Safer model-authored code:** `wait_agent` and `write_stdin` limits inside raw `exec` cannot be
  bypassed with getters or `toJSON`. One validator now serves MCP and raw `exec`.
- **Linux:** the desktop entry works from paths with spaces and special characters, the installer
  identifies the running launcher reliably, and AppImage extraction is safe under concurrent launches.
- **Updates stay on this fork:** the in-app updater and installers now use this repository's
  releases, so later updates keep these fixes.
- **Clean dependency audit:** fixes GHSA-8g5g-mxqh-grgj (vite) and GHSA-g3hv-75wg-m249 (minimatch),
  which upstream v6.1.17 still reports.
- **95 more passing regression tests** than upstream: 1172 core and 467 launcher tests, against
  1113 and 431.

### Before you update

- **Coming from an upstream install?** Download a build below once; after that, **Update** in the
  launcher follows this fork.
- **Temporary Chat is now the default.** This is an upstream change from v6.1.15. New task
  conversations no longer appear in your ChatGPT history. To keep them there, rerun setup with
  `--ordinary-chats`.
- Every file below is listed in `checksums.txt` with its SHA-256 hash. The launcher verifies it
  before installing an update.
