## Fork release 6.1.17-fork.1

Upstream [codex-chatgpt-web v6.1.17](https://github.com/miuuyy/codex-chatgpt-web/releases/tag/v6.1.17)
plus this fork's fixes, with one launcher change.
**[See everything that differs from upstream →](https://github.com/Y0UW1SH/chatgpt-web-codex/blob/main/docs/fork-changes.md)**

### What's new since v6.1.17

- **The launcher now recognizes fork releases.** Fork-only fixes ship between upstream syncs as
  `X.Y.Z-fork.N`. This version's **Update** button offers later fork releases and the next upstream
  sync, and never offers an older build.

### Updating from v6.1.17

The v6.1.17 launcher predates this numbering and will report that it is up to date. **Install this
release once by hand.** After that, **Update** works as usual. Either:

- download the file for your system below, or
- run the install command from the [README](https://github.com/Y0UW1SH/chatgpt-web-codex#get-started)
  again; it always picks the latest release.

Nothing else changes. Settings, models and behavior are the same as v6.1.17, including upstream's
Temporary Chat default. Every file below is listed in `checksums.txt` with its SHA-256 hash.
